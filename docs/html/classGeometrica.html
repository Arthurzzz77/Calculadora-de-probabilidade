Detailed Description

Distribuicao Geometrica.

Modela o numero de tentativas necessarias ate obter o primeiro sucesso em experimentos independentes com probabilidade de sucesso p

P(X = k) = (1 - p)^(k-1) * p, k = 1, 2, 3, ...
