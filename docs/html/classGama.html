Detailed Description

Distribuicao Gama.

Modela o tempo de espera ate a ocorrencia do k-esimo evento num processo de Poisson, generalizando a distribuicao Exponencial

f(x) = (taxa^forma / Gamma(forma)) * x^(forma-1) * e^(-taxa*x), x >= 0
