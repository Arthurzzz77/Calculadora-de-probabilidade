Detailed Description

Distribuicao Beta.

Modela variaveis aleatorias continuas restritas ao intervalo [0, 1], sendo util para representar probabilidades e proporcoes

f(x) = x^(alfa-1) * (1-x)^(beta-1) / B(alfa, beta), x in [0, 1]
