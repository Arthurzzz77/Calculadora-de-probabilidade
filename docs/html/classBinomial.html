Detailed Description

Distribuicao Binomial.

Modela o numero de sucessos em n tentativas independentes, cada uma com probabilidade de sucesso p

P(X = k) = C(n, k) * p^k * (1-p)^(n-k), k in {0, 1, ..., n}
