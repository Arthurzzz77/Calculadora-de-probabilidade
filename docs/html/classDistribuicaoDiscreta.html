Detailed Description

Classe base abstrata para distribuicoes de probabilidade discretas.

Distribuicoes discretas calculam probabilidades em valores inteiros isolados. Esta classe adiciona a interface de probabilidade pontual P(X = k) e acumulada P(X <= k) a hierarquia de Distribuicao, que subclasses como Bernoulli, Binomial e Poisson devem implementar
